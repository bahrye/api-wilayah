API Wilayah Administrasi

API Wilayah Indonesia

Akses data Provinsi, Kabupaten, Kecamatan, dan Desa seluruh Indonesia secara cepat, gratis, dan mudah digunakan.

Daftar Provinsi

Mendapatkan seluruh daftar provinsi di Indonesia.

GET
/api/provinsi

Daftar Kabupaten/Kota

Mendapatkan daftar kabupaten berdasarkan kode provinsi.

GET
/api/kabupaten?provinsi=11

Daftar Kecamatan

Mendapatkan daftar kecamatan berdasarkan kode kabupaten.

GET
/api/kecamatan?kabupaten=11.01

Daftar Desa/Kelurahan

Mendapatkan daftar desa berdasarkan kode kecamatan.

GET
/api/desa?kecamatan=11.01.01

Detail Wilayah

Mendapatkan detail dari satu kode wilayah spesifik.

GET
/api/detail?kode=11.01.01.2001
